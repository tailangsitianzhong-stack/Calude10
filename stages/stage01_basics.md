# 第1段階：株式投資の基礎理論

> 作成日：2026-11-03。本段階ではリアルタイムデータを取得していない。数値は記憶にある公開情報に基づき、
> 確度が高いものは【事実】、一次資料で未照合のものは【要検証】と明示する。銘柄推奨は行わない。

## 1.1 株式市場の仕組み

**発行市場と流通市場**【事実】
- 発行市場（プライマリー）：企業がIPO・公募増資で新株を発行し資金を調達する場。企業に資金が入るのはここだけ。
- 流通市場（セカンダリー）：既発行株を投資家間で売買する場。企業の資金は直接増えないが、流動性があるから発行市場が成り立つ。株価は将来の資金調達コスト・M&A通貨・経営者報酬に影響するため、企業にとっても無関係ではない。

**注文から決済まで（日本の例）**【事実】
投資家 → 証券会社 → 取引所（東証の売買システム arrowhead）で約定 → 日本証券クリアリング機構（JSCC）が清算（取引相手リスクを引き受ける）→ 証券保管振替機構（ほふり）で株式の振替。
決済期間：日本は2019年7月からT+2、米国は2024年5月28日からT+1。

**機能面の本質**【推測】
市場は「価格発見」「流動性供給」「リスク移転」の装置。実務上重要なのは、価格は「正しい価値」ではなく「その時点で最後に約定した限界的な買い手と売り手の合意」にすぎないこと。全株式のごく一部の売買が全体の時価総額を決める。

## 1.2 株価が変動するメカニズム

**価格形成の方式**【事実】
- 東証：寄付き・引けは**板寄せ**（注文を集めて単一価格で一括約定）、取引時間中は**ザラバ**（価格優先・時間優先の継続オークション）。2024年11月5日から後場の取引終了が15:30に延長され、引けにクロージング・オークションが導入された。
- 成行注文は価格優先で最優先、指値は価格の条件付き。
- **値幅制限**：日本は前日終値基準で1日の変動幅に上限（ストップ高・ストップ安）。米国は個別株にLULD（Limit Up-Limit Down）、市場全体にS&P500基準のサーキットブレーカー（7%・13%・20%）。

**株価の理論的な決定要因**【通説】
株価 ＝ 将来キャッシュフロー（配当・FCF）の期待値 ÷（リスクフリー金利 ＋ リスクプレミアム − 成長率）という割引モデルで考えると、株価を動かす要因は3つに分解できる。
1. **期待利益・キャッシュフローの変化**（決算、ガイダンス、景気）
2. **金利の変化**（割引率の分子ではなく分母）
3. **リスクプレミアムの変化**（投資家のリスク許容度、不確実性、センチメント）

短期の値動きの大部分は2と3（とくに3）、長期の値動きは1が支配的になる傾向がある【通説：Shiller(1981)は株価変動が配当変動で説明できる以上に大きい「過剰ボラティリティ」を指摘】。

**ニュースと株価**：株価が反応するのは「ニュースの良し悪し」ではなく「市場予想との差（サプライズ）」。好決算で株価が下がるのは、期待がそれ以上だったか、ガイダンスが弱かったか、既に織り込まれていたため。

## 1.3 需要と供給、需給バランス

株価は需給で決まるが、需給には「ファンダメンタルズ由来」と「非ファンダメンタルズ由来」がある。後者の代表例【事実】：
| 需給要因 | 仕組み | 典型的な影響 |
|---|---|---|
| 指数リバランス | 指数採用・除外、浮動株比率変更でパッシブ資金が機械的に売買 | 採用前後に一時的な価格圧力 |
| 信用取引 | 信用買い残は将来の売り需要、信用売り残は将来の買い戻し需要 | 買い残の積み上がりは上値を重くしやすい。貸借倍率で見る |
| 空売り | 借株売り。踏み上げ（ショートスクイーズ）で急騰することがある | 2021年のGameStop事例が典型 |
| 増資・売出し | 1株価値の希薄化と供給増 | 発表後に下落しやすい（資金使途次第） |
| ロックアップ解除 | IPO後の大株主の売却制限が解除 | 解除前後に供給懸念 |
| 自社株買い | 企業自身が買い手になる | 需給改善＋シグナリング |
| 配当・決算期末 | 権利取り・配当再投資・ドレッシング | 季節的な需給 |

**日本固有の需給データ**【事実】：JPXが週次で「投資部門別売買状況」を公表（海外投資家、個人、信託銀行、事業法人など）。日本株では売買代金の過半を海外投資家が占める状況が長く続いている【要検証：最新比率はJPX統計で確認】。

## 1.4 株式市場の歴史と金融危機

| 出来事 | 内容 | 教訓 |
|---|---|---|
| 1929年 大恐慌 | ダウ平均は1929年高値から1932年安値まで約89%下落。名目で高値回復は1954年 | レバレッジ（信用取引）と銀行破綻・金融引き締めの連鎖。「回復まで25年」は配当・デフレ考慮で実質的には短いとの指摘もある |
| 1987年 ブラックマンデー | 10月19日にダウ平均が1日で約22.6%下落 | ポートフォリオ・インシュアランス（機械的売り）による流動性崩壊。後にサーキットブレーカー導入 |
| 1989〜 日本のバブル崩壊 | 日経平均は1989年12月29日の終値38,915.87円が史上最高値。2009年3月には7,000円台まで下落。最高値更新は2024年2月22日 | 高PER（当時60倍前後【要検証】）・土地担保融資・持ち合い。**優良市場でも高値で買うと34年報われないことがある** |
| 2000年 ITバブル | NASDAQ総合は2000年3月の約5,048から2002年10月まで約78%下落 | 「技術は本物でも株価は過大」になりうる。成長産業≠良い投資 |
| 2008年 世界金融危機 | 2008年9月15日リーマン・ブラザーズ破綻。S&P500は2007年10月高値から2009年3月まで約57%下落 | 住宅ローン証券化とレバレッジ、相関の急上昇で分散が効かなくなる |
| 2020年 コロナショック | S&P500は2020年2月19日から3月23日までの約1か月で約34%下落、その後急回復 | 外生ショック＋中央銀行・財政の大規模介入。底値で売った投資家が最も損をした |
| 2022年 インフレ・利上げ | FRBの急速な利上げで株と債券が同時下落。NASDAQは高値から30%超下落 | 金利上昇はデュレーションの長いグロース株ほど打撃。株債の負の相関は常に成り立つわけではない |
| 2024年8月5日 日本株急落 | 日経平均が1日で4,451円（約12.4%）下落し、下げ幅は過去最大。翌日に大幅反発 | 円キャリートレード巻き戻し・日銀利上げ・米景気懸念が重なった需給起因の急落 |

**危機の共通パターン**【推測：上記事例からの帰納】
1. 直前に「今回は違う」という物語と高いバリュエーション、またはレバレッジの積み上がりがある。
2. 引き金は一見小さく、伝播経路（強制売却・流動性枯渇）が下落を増幅する。
3. 危機時には資産間の相関が1に近づき、分散効果が薄れる。
4. 回復は「どこまで下がったか」より「バリュエーションと政策対応」で決まる。

## 1.5 市場構造：東証、NYSE、NASDAQ

**東京証券取引所**【事実】
- 2022年4月4日に市場区分を再編：**プライム**（流動性・ガバナンス水準が最も高い、グローバル投資家向け）、**スタンダード**、**グロース**（高い成長可能性、赤字企業も上場可）。
- 2023年3月、東証はPBR1倍割れが続く企業などに「資本コストや株価を意識した経営」の対応を要請。これ以降、自社株買い・増配・政策保有株の売却が加速した【事実（傾向）／効果の大きさは要検証】。
- 売買単位は原則100株。

**NYSE**【事実】：指定マーケットメーカー（DMM）が担当銘柄の価格の安定・寄付き・引けのオークションに関与する、人間と電子のハイブリッド型。
**NASDAQ**【事実】：複数のマーケットメーカーが気配を競う完全電子取引所として発展。
**米国市場の特徴**【事実】：Reg NMS（2005年）により、同一銘柄が多数の取引所・ATS（ダークプール含む）で取引される分散型市場。全米最良気配（NBBO）への執行義務がある。個人注文の多くは取引所外のホールセラー（マーケットメーカー）で執行され、ペイメント・フォー・オーダーフロー（PFOF）が議論の的。

**構造が投資家に与える影響**【推測】：日本は値幅制限があるため急落が複数日に分散されやすく（売りたくても売れない日が続く）、米国は1日で価格が大きく動く代わりに流動性は確保されやすい。

## 1.6 市場参加者の行動

| 参加者 | 目的・制約 | 行動の特徴 |
|---|---|---|
| 個人投資家 | 自己資金、税制（日本は2024年から新NISA） | 逆張り傾向が強い（日本の個人は下落時に買い越しやすい）【通説】。過剰売買・気質効果が観察される |
| 年金基金（例：GPIF） | 長期・基本ポートフォリオに沿った配分 | 定期的なリバランス（上がった資産を売り、下がった資産を買う） |
| 投資信託・アクティブ運用 | ベンチマーク相対の評価 | キャリアリスクから群れやすい。四半期末のウィンドウドレッシング |
| パッシブ（インデックス） | 指数に完全連動 | 価格を見ずに資金流入額に応じて機械的に買う。シェア拡大が価格発見に与える影響は論争中 |
| ヘッジファンド | 絶対リターン、レバレッジ、ショート可 | ロングショート、マクロ、イベント、クオンツなど多様。レバレッジ解消時に急激な売りを起こしうる |
| HFT・マーケットメーカー | ミリ秒単位の売買、スプレッド収入 | 平時は流動性を供給、ストレス時には撤退することがある |
| 事業法人 | 自社株買い、持ち合い | 日本では持ち合い解消の売りと自社株買いの買いが併存 |
| 中央銀行 | 金融政策 | 日銀は2010年からETFを購入し、2024年3月に新規購入を終了 |

**ポイント**【推測】：同じ株価下落でも、誰が売っているか（強制的な売りか、自発的な売りか）で意味が全く異なる。強制売却（マージンコール、償還、リバランス）による下落は、ファンダメンタルズと無関係な割安を生みやすい。

## 1.7 長期・中期・短期投資

| 期間 | 主なリターン源泉 | 必要な能力 | 主なコスト・リスク |
|---|---|---|---|
| 長期（5年以上） | 企業利益の成長、配当再投資、複利 | 事業理解、価値評価、忍耐 | 機会損失、長期停滞（例：1990〜2010年代の日本） |
| 中期（数か月〜数年） | 業績サイクル、バリュエーション修正、カタリスト | 業績予測、市場期待との差の把握 | 予想外れ、マクロ変動 |
| 短期（日〜週） | 需給の歪み、モメンタム、イベント | 執行・リスク管理・規律 | 取引コスト、税、情報優位を持つ相手との競争 |

【事実（実証研究）】Barber & Odean (2000) は米国個人投資家の口座データで、売買頻度が最も高いグループのネットリターンが市場を大きく下回ったことを示した。短期売買は「ゼロサムからコストを引いたマイナスサム」に近い。

## 1.8 配当、株式分割、自社株買い

**配当**【事実】：権利付最終日までに保有していれば受け取れる。権利落ち日には理論上、配当相当額だけ株価が下がる（例：株価1,000円・配当30円 → 理論値970円）。**配当は株主価値の「移転」であり「創出」ではない**（MM理論・税と取引コストを無視した場合）。配当を受け取っても総資産は増えず、課税が発生する分だけ不利になりうる。それでも配当が重視されるのは、経営規律（無駄な投資の抑制）とシグナリング効果があるため【通説】。

**株式分割**【事実】：1株を複数株に分けるだけで、企業価値・持分比率は不変。ただし最低投資額の低下による流動性向上・個人投資家の参入という需給効果はある。分割発表後の株価上昇は、分割自体より「経営者が業績に自信を持っている」というシグナルと解釈されることが多い【通説】。

**自社株買い**【事実＋推測】
- 発行済株式数が減るためEPSは上昇する。しかし**EPS上昇＝価値創造ではない**。
- 適正価格で買うなら、残った株主の1株価値は変わらない（現金が出て行き株数が減るだけ）。
- **割安な価格**で買えば残存株主の価値は増え、**割高な価格**で買えば減る。自社株買いの評価は「いくらで買ったか」で決まる。
- 株式報酬による希薄化を打ち消すだけの「見せかけの自社株買い」も多い。純減株数を確認すべき。

## 1.9 複利、リスクとリターン

**複利**【事実：計算】（実践課題で検証済み）
- 100万円を年5%で20年 → 約265万円、30年 → 約432万円。年7%で30年 → 約761万円。
- **72の法則**：資金が倍になる年数 ≒ 72 ÷ 年利率(%)。6%なら12年（正確には11.9年）。

**算術平均と幾何平均（ボラティリティ・ドラッグ）**【事実：数学】
- +50%の翌年に−50% → 算術平均0%だが資産は0.75倍（−25%）。
- 近似式：幾何平均 ≒ 算術平均 − 分散/2。期待リターン8%・ボラティリティ20%なら、複利の実効リターンは約6%。
- **下落からの回復に必要な上昇率**：−10%→+11.1%、−20%→+25%、−30%→+42.9%、−50%→+100%、−80%→+400%。大きな損失を避けることが複利にとって決定的に重要。

**リスクとリターン**【通説】
- 株式の長期リターンは債券・現金を上回ってきた（株式リスクプレミアム）が、これは**下落・長期停滞に耐える対価**であり保証ではない。
- 米国株の長期名目リターンは年率約10%前後というのが代表的な推計だが、国・期間により大きく異なる（日本の1990〜2010年代は大幅に下回った）。米国は「生き残った成功市場」であり、そのデータをそのまま将来に当てはめると生存者バイアスが入る【要検証：Dimson-Marsh-Stauntonの国際長期データで確認】。
- **期待値と中央値の違い**（実践課題のシミュレーション）：平均8%・ボラ20%で30年運用した場合、資産倍率の**平均は約10倍だが中央値は約6倍**、下位10%は約1.5倍。「平均的な結果」は多くの投資家が実際に得る結果ではない。
- リスク指標：標準偏差（ボラティリティ）、最大ドローダウン、ベータ、シャープレシオ（超過リターン÷ボラティリティ）。ボラティリティは「価格の揺れ」であり、本当のリスク＝「恒久的な資本損失」とは異なる、という見方もある（バフェット等）【通説・見解の対立あり】。

## 1.10 投資心理学と行動経済学

| 概念 | 内容 | 根拠 | 投資での現れ方 |
|---|---|---|---|
| プロスペクト理論 | 価値は参照点からの損益で評価され、損失は同額の利益より重く感じる | Kahneman & Tversky (1979)。損失回避係数は約2.25と推計（Tversky & Kahneman 1992） | 含み損を確定できない |
| 気質効果 | 利益の出た株を早く売り、損失の出た株を長く持つ | Shefrin & Statman (1985)、Odean (1998) | 「利小損大」 |
| 過信 | 自分の情報・能力を過大評価 | Barber & Odean (2000, 2001) | 過剰売買、集中投資 |
| アンカリング | 最初の数値（取得価格、過去高値）に判断が引きずられる | Tversky & Kahneman (1974) | 「買値に戻ったら売る」 |
| 確証バイアス | 自説に合う情報ばかり集める | 心理学の実験研究 | 反対意見を読まない |
| 群集行動 | 他者に追随する | 多数の実証 | バブルと暴落の増幅 |
| 近視眼的損失回避 | 頻繁に評価するほど損失を感じやすい | Benartzi & Thaler (1995) | 毎日チェックするとリスク資産を減らしすぎる |
| 後知恵バイアス | 結果を知ってから「予測できた」と思う | Fischhoff (1975) | バックテストの過信 |

**効率的市場仮説との関係**【通説・論争あり】
- 効率的市場仮説（Fama）：価格は利用可能な情報を速やかに反映する → 継続的な超過リターンは困難。
- 行動ファイナンス：バイアスによる価格の歪みは存在するが、「裁定の限界」（Shleifer & Vishny 1997）のため歪みが長く続きうる → 「歪みが存在する」ことと「それで儲けられる」ことは別。
- 実証的には、アクティブファンドの大多数は長期的にインデックスに負けている（S&P SPIVAレポート）【事実（傾向）／最新比率は要検証】。これは市場がかなり効率的であることの強い証拠。
- 【推測】実務上の合理的な立場：「市場はおおむね効率的だが完全ではない。超過リターンを狙うなら、自分が持つ優位性（情報・分析・時間軸・行動規律）を説明できなければならない」。

# 理解度テスト（第1段階）

各問の模範解答は末尾。80%（20問中16問）以上を合格とする。

**A. 概念問題**
1. 企業が直接資金を得るのは発行市場と流通市場のどちらか。流通市場が企業にとって重要な理由を1つ挙げよ。
2. 東証の「板寄せ」と「ザラバ」の違いを説明せよ。
3. 割引モデルの観点から、株価を動かす3つの要因を挙げよ。
4. 好決算なのに株価が下落する理由を2つ挙げよ。
5. 信用買い残が大きく積み上がっている銘柄で注意すべきことは何か。
6. 2022年に株と債券が同時に下落した理由を説明せよ。
